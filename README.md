# 五线谱识音

从四个锚点开始，一次认准一个音，逐圈扩大练习范围。适合已经了解五线谱基本规则、希望通过大量练习提高识音熟练度的学习者。

## 开始练习

在线练习：[打开五线谱识音](https://sisyphunky.github.io/music-reading-practice/)。

1. 建议用 Safari、Chrome 或 Edge 等常用浏览器打开，尽量固定使用同一台设备、同一个浏览器。
2. 看谱后依次选择音名和音组，选齐后提交答案。页面会显示反馈、琴键位置，并可播放合成音。
3. 自动模式按第一圈至第四圈逐步扩大范围，通过后进入混合巩固。每组 20 题结束时检查晋级条件。
4. 可在“进度”查看表现，在“设置与备份”切换模式、开关声音或导出记录。

手机练习时默认收起页首和主导航。答完题后，底部显示听音按钮和「下一题」；上下滑动时，同一位置显示「练习／进度／设置」。滑动停稳约 3 秒，主导航收起，答题操作重新出现。

本工具练习单音识别，暂不包含节奏、多音旋律或真实演奏识别。

## 练习记录如何保存

- 无需注册。答题记录和进度保存在当前设备、当前浏览器的网站存储（IndexedDB）中，应用不会上传答题记录，也没有账号或云同步。
- 清除“网站数据”、结束无痕浏览、浏览器回收存储或设备故障，可能导致记录丢失。只清除图片等缓存通常不同于清除网站数据，请留意浏览器选项。
- 换设备、换浏览器或从社交平台内置浏览器切换到系统浏览器，记录不会自动跟随。
- 请定期导出 JSON 备份，并确认文件已实际保存。需要迁移时，在新入口导入备份；页面会先显示导入预览，重复记录不会重复计算。
- 从本地试用网址迁移到正式网址，也需要先导出、再导入。
- 网站和代码公开；各使用者的练习记录独立保存在各自浏览器中。GitHub 托管服务可能处理正常网页访问所需的请求信息。

## 练习与晋级

- A–D 对应四圈，E 为混合巩固；高、低音谱表中的中央 C 分开统计。
- 每组 20 题，高、低音各 10 题。第一圈以均衡练习为主；第二至第四圈以新增音为主，穿插薄弱音和旧音；E 综合巩固。
- 自动晋级综合参考本阶段至少 40 题、高低音最近各 20 题至少答对 18 题、每个新增音的近期准确性与 4 秒速度要求，以及旧音错误是否纠正。
- 手动模式单独记录，不改变自动模式的解锁进度；不会因出错而自动降级。
- 暂停或进入后台会停止计时。刷新时未完成的题目可以恢复，但该题不用于速度达标。

这些阈值是当前版本的练习规则，仍需根据实际使用效果校准。

## 当前版本与限制

- 版本：1.3.1（2026-11-18）。
- 本次发布前用两个手机窗口尺寸与桌面尺寸验证了答题、反馈、底部按钮切换、续练和晋级。不同手机浏览器的真实触控与扬声器表现可能有所差异。
- 音频使用合成音。首次播放可能需要用户点击后才有声音。
- 尚未提供完整离线缓存、云同步及后续加线扩展课程。

## 部署

仓库根目录包含可直接运行的 `index.html`，无需安装依赖或构建。

本仓库已启用 GitHub Pages，发布来源为 **main** 分支的 **/(root)**。后续提交到 main 后，GitHub 自动重新部署；可在仓库的 Actions 中查看发布结果。

若自行复制部署，在 **Settings → Pages** 中选择 **Deploy from a branch → main → /(root)** 并保存。

部署参考：[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。
